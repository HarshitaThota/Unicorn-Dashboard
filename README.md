# Unicorn Companies Analytics Dashboard (Excel)

This project presents an interactive Excel dashboard that analyzes global unicorn companies using descriptive analytics. It explores key performance indicators (KPIs) related to valuation, funding, investor trends, and geographic distribution.

## 📊 Features

- **Interactive Excel Dashboard** with slicers for filtering by continent, industry, and investor.
  
- **Descriptive Analysis** of:
  - Time taken for companies to reach unicorn status
  - Top countries and cities producing unicorns
  - Most active investors and their industry focus
 
- **KPI Tracking** including:
  - Valuation (converted from billions to millions)
  - Total funding raised
  - Investor frequency
    
- **Excel Functions Used**:
  - `IF`, `SUBSTITUTE`, and `VLOOKUP` for data cleaning and transformation
  - Aggregate formulas to analyze time-to-unicorn and funding trends
  - Pivot tables and charts for dynamic visualizations

## 📁 Data Source

The dataset was obtained from [Maven Analytics' Data Playground](https://www.mavenanalytics.io/data-playground?accessType=open&order=date_added%2Cdesc&page=1&pageSize=5&tags=Finance&tags=Healthcare&tags=Human%20Resources), which provides open-access data for analysis projects.

## 🎯 Objective

This project aims to demonstrate proficiency in Excel for real-world data analysis, using structured logic and clear visualization to uncover trends in the global unicorn startup ecosystem.
